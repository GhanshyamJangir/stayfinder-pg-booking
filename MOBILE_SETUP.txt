STAYFINDER MOBILE/LAN SETUP
===========================

1) Copy these files into the PG Booking New project:
   app/page.js
   next.config.js
   Start-Mobile.bat

2) IMPORTANT FOR next.config.js
   If your existing next.config.js contains any custom settings that are not present in this file,
   merge those settings instead of deleting them. The two required settings for this mobile fix are:

   allowedDevOrigins: ['172.150.1.165', 'localhost', '127.0.0.1']
   turbopack: { root: path.resolve(__dirname) }

3) Close the old development server with Ctrl+C.

4) Clear Next cache:
   rmdir /s /q .next

5) Double-click Start-Mobile.bat
   OR run:
   npm run dev -- -H 0.0.0.0 -p 5555

6) Windows Firewall
   If Windows asks for Node.js network access, allow Private networks.
   Phone and PC must be connected to the same Wi-Fi/LAN.

7) Open on PC:
   http://localhost:5555

8) Open on phone:
   http://172.150.1.165:5555

9) Test in this order:
   A. Login page opens on phone.
   B. Show/Hide changes password visibility.
   C. Login using an existing Guest/Host account.
   D. Create a new test Guest account.
   E. Logout and log back in with that new account.
   F. Test Guest bottom navigation.
   G. Test Host bottom navigation.

10) If the PC IP changes later:
    Run: ipconfig
    Find the current IPv4 Address.
    Replace 172.150.1.165 in:
      - next.config.js allowedDevOrigins
      - Start-Mobile.bat display URL (optional)
    Then restart the server.

11) NOTE
    This is the local mobile test setup. Vercel deployment does not require the phone and PC to be on the same Wi-Fi.
