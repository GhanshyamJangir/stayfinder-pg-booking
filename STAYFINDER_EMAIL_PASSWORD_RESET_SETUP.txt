STAYFINDER EMAIL + FORGOT PASSWORD SETUP
========================================

WHAT IS INCLUDED
- Forgot password link on the login page.
- Registered email/username -> 6 digit OTP by email.
- OTP valid for 10 minutes, maximum 5 wrong attempts.
- OTP verification is required before the new password fields are unlocked.
- New password + re-enter password validation.
- Password is bcrypt-hashed before it is stored in the Users sheet.
- Password changed confirmation email.
- Account creation email.
- Booking request, accept/reject, payment submit/verify/reject emails.
- Refund initiated/sent/received/disputed emails.
- Support ticket created/updated emails.
- Chat message and review emails.
- Customer profile update email.

IMPORTANT ABOUT PASSWORDS IN GOOGLE SHEETS
The value stored in the Password column is a bcrypt hash. It is intentionally one-way and the original password cannot be viewed or decoded. This is the secure/correct design. If a user forgets a password, use the OTP reset flow; never try to recover the old password.

GMAIL / VERCEL SETUP
1. Use a Gmail/Google Workspace account that will send StayFinder emails.
2. Turn on 2-Step Verification on that Google account.
3. Create an App Password for StayFinder (Google Account > Security > App passwords).
4. In Vercel > Project > Environment Variables add these for Production:

MAIL_USER=yourgmail@gmail.com
MAIL_APP_PASSWORD=16-character-app-password
MAIL_FROM_NAME=StayFinder
SUPPORT_EMAIL=Ghanshyamjangir334@gmail.com
NEXT_PUBLIC_APP_URL=https://stayfinder-pg-booking.vercel.app

Do NOT put the normal Gmail password in MAIL_APP_PASSWORD.
Do NOT commit real mail credentials to GitHub.

After adding/changing Vercel environment variables, redeploy the Production deployment.

GOOGLE SHEET
A new sheet named PasswordResetOTPs is created automatically on first use. Do not manually store plain-text OTPs or passwords.

TEST ORDER
1. Create a Guest/Host account using a real email.
2. Logout.
3. Click Forgot password? on the login screen.
4. Enter the registered email or username.
5. Check email for the 6 digit OTP.
6. Verify OTP.
7. Enter New password and Re-enter new password.
8. Login using the new password.
9. Confirm the password changed email arrived.

If email sending is not configured, existing booking/payment processes continue working; only email delivery/password-reset OTP sending will report a mail setup error.
